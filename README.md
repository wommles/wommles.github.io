# Dominic Aldridge — Professional Portal

React + Vite site hosted at [wommles.github.io](https://wommles.github.io/).

## Develop

```bash
npm install
npm run dev
```

## Customize

Edit `src/data/profile.ts` for name, bio, projects, and adventures.

## Deploy

```bash
npm run build
git add docs
git commit -m "Update site build"
git push
```

In the repo **Settings → Pages**, set **Source** to **Deploy from a branch**, branch **main**, folder **/docs**.
